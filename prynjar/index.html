02 / Your working tree

Read carefully.
Leave the code alone.

Pointing a new tool at your working copy is a matter of trust. PRynjar’s review engine is built to leave your files, index and branches alone.

What enforces that →
13 mutating git verbs refused
A build-failing architecture check covers commands including checkout, reset, merge, commit and push.
Your review stays on this machine
Drafts and reading marks live in a local SQLite store outside the working tree. Already-fetched changes can be reopened offline.
The platform is optional
Review two refs or uncommitted work locally. Connect GitHub or GitLab when you need hosted conversations and batched submission.

Where it honestly stands

Working software.
Still being tested.

Only the author has used PRynjar so far. A review of the implementation is in progress. There are no customer stories to put here yet.

  • Windows and Linux. Windows builds are unsigned. macOS is not supported and is not planned.
  • Cold open is not instant. The recorded 8,000-file journey took 6,636 ms against the original 800 ms target.
  • Enterprise GitHub is unverified. No enterprise tenant has been available to test.
  • A keyboard rough edge remains. Menu titles currently need a pointer; their commands have keyboard bindings.
